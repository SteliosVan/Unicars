# Unicars

## 1. Installation & Usage Instructions

This is an Android application developed using Flutter.

### Installation
1. Download the APK file.
2. Enable "Install unknown apps" on your Android device.
3. Open the APK file and install the application.
4. Launch the application from the home screen.

### Usage
- Η εφαρμογή αυτή συνδέει φοιτητές που διαθέτουν αυτοκίνητο και πραγματοποιούν καθημερινά τη διαδρομή προς το πανεπιστήμιο, με συμφοιτητές που αναζητούν άνετη, οικονομική και ευέλικτη μετακίνηση
- Για να πραγματοποιηθεί η εγγραφή  απαιτείται η εισαγωγή valid gmail στο RegisterScreen.
- Στην main οθόνη μπορείς: 
    - Να κάνεις request για μελλοντική σου διαδρομή (Πατώντας το πράσινο  κουμπί που λέει "Find Ride" και συμπληρώνοντας τα στοιχεία που απαιτούνται - Departure Location/Destination University) - μετά την ολοκλήρωση του request εμφανίζεται μία οθόνη με όλους τους διαθέσιμους οδηγούς που κατευθύνονται στην τοποθεσία που ζητάς
    - Να κάνεις offer μελλοντική σου διαδρομή (Πατώντας το κουμπί που λέει "Offer Ride" και συμπληρώνοντας τα στοιχεία που απαιτούνται - Departure Location/Destination University/Seats Available)
    - Να επεξεργαστείς τα στοιχεία προφίλ σου (Πατώντας το profile Icon κάτω δεξιά)
    - Να συνομιλήσεις με τα άτομα που έχεις ήδη γίνει match, ώστε να συννενοηθείς για τις διαδρομές σου
    - Να δεις αν έχει κάνει κάποιος request για την διαδρομή που έχεις κάνει offer (Πατώντας "See Ride Requests") 

- Στην chat οθόνη μπορείς: 
    - Να ανταλλάξεις μηνύματα με τον άλλον χρήστη
    - Να δεις πληροφορίες για αυτόν - όπως Όνομα/Επίθετο/Τηλέφωνο/Ημερομηνία Γέννησης/Πανεπιστήριο καθώς και την τρέχουσα τοποθεσία του. Επίσης υπάρχει σύστημα αξιολόγησης με αστεράκια (1-5) καθώς και σχόλια για να διασφαλιστεί η ποιότητα του οδηγού-επιβάτη

- Ανα πάσα στιγμή μπορείς να γυρίσεις πίσω στην main screen πατώντας το logo της εφαρμογής 

## 2. Android SDK / Emulator Requirements

- Target Android SDK: Latest Flutter-supported Android SDK
